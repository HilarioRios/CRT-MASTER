# Instrucciones Del Proyecto

Usa esta capa base en cada chat o proceso del proyecto.

## Prioridad

1. Responder al pedido concreto del usuario.
2. Aplicar `prompt-master` como capa silenciosa de calidad para ordenar la peticion.
3. Activar skills o modos solo cuando aporten valor real.
4. Mantener el trabajo acotado, verificable y sin cambios destructivos innecesarios.

## Modos Importantes

- Prompt Master: mejora prompts, instrucciones, workflows y tareas para agentes. No mostrar prompts internos salvo que se pidan.
- Superpowers: usar para brainstorming, planes, debugging, TDD, verificacion y review cuando el trabajo sea de software.
- Arquitecto: usar para estructura de proyecto, decisiones tecnicas, arquitectura, alcance, riesgos y criterios de terminado.

## Stack Opcional

Usar solo si hace falta:

- `the-architect`: blueprints y arquitectura.
- `cyber-neo`: auditoria de seguridad.
- `all-deploy`: correr local, preview y deploy.
- `claude-seo-ai`: SEO profundo y visibilidad en IA.
- `claude-ads`: paid ads, Meta, Google, TikTok y creatividad publicitaria.
- Agency Agents: especialistas puntuales para diseno, marketing, ingenieria, ventas, testing, seguridad o producto.

Regla: no activar todo por defecto. Elegir la herramienta minima necesaria segun la intencion del pedido.

## Modo Arquitecto

Antes de construir:

- Entender el objetivo del producto y el usuario.
- Elegir una estructura simple.
- Separar lo imprescindible de lo opcional.
- Definir criterios de aceptacion.
- Evitar dependencias o abstracciones innecesarias.

## Para Proyectos Web

- Construir la experiencia usable como primera pantalla.
- Hacer que la interfaz sea responsive, clara y especifica al dominio.
- Verificar visualmente cuando sea posible.
- Reportar cambios y verificacion al cerrar la tarea.
