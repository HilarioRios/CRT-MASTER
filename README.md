# CRT-MASTER

Material del proyecto de Gustavo Trading (curso CRT).

| Carpeta | Contenido |
|---|---|
| `Landing Page/` | Código de la página del curso (Vite + funciones de Netlify/Vercel) |
| `PDFs CURSO CRT - para subir a Drive/` | PDF del curso por capítulo y e-book completo |
| `VSL/` | Guion del VSL y material de referencia |
| `Estrategia de Ads/` | Análisis de anuncios de referencia y guiones de anuncios |
| `gustavo-second-brain/` | Segundo cerebro: transcripciones procesadas, base de conocimiento y scripts |
| `Copia de PACK DE HERRAMIENTAS/` | Pack de herramientas |

## Qué no está en el repositorio

- Archivos `.env`, credenciales y tokens. Cada proyecto trae su `.env.example` con las variables que necesita.
- Dependencias (`node_modules`, `.venv`) y carpetas generadas (`dist`).
- Datos crudos y bases SQLite del segundo cerebro, que se regeneran con sus scripts.
- Los videos y capturas de los anuncios de referencia.
